# VCT Champions 2026: сайт с сеткой, группами и расписанием

Статический сайт без сборки и серверной части. Работает на GitHub Pages как есть.

## Что внутри

- **Обзор**: ближайший матч с обратным отсчётом, матчи сегодняшнего дня, кто остался в плей-офф.
- **Плей-офф**: верхняя и нижняя сетка, клик по команде подсвечивает её путь.
- **Группы**: таблицы GSL с результатами и статусами (в плей-офф или вылет).
- **Расписание**: время в выбранном часовом поясе, фильтры «Все / Предстоящие / Сыгранные».
- **Команды**: все 16 участников, фильтры по статусу и региону, поиск, «моя команда» (звёздочка).
- **Гайд**: сопоставление CS и Valorant, термины формата, где смотреть.
- Выбор часового пояса, «моя команда» и тема (светлая, тёмная, авто) запоминаются в браузере.

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в корень файлы: `index.html`, `data.js`, папку `assets`.
2. В репозитории откройте Settings, раздел Pages.
3. В Source выберите ветку `main` и папку `/ (root)`, сохраните.
4. Через минуту-две сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Сайт можно открыть и локально: достаточно дважды кликнуть `index.html`.

## Как обновлять результаты

Все данные лежат в одном файле, `data.js`. Таблицы, сетка, расписание и статусы команд пересчитываются сами.

**Записать результат матча плей-офф.** Найдите матч по `id` в блоке `playoffs` и допишите счёт по картам:

```js
{ id: "UB-QF3", ..., a: "100T", b: "G2", sa: 2, sb: 0 }
```

`sa` это счёт стороны `a`, `sb` стороны `b`. После этого победитель сам перейдёт в следующий матч, а проигравший в нижнюю сетку. Ссылки вида `"W:UB-QF3"` (победитель) и `"L:UB-QF3"` (проигравший) подставят названия команд автоматически.

**Назначить время матча.** Впишите `startUtc` в формате UTC, например `"2026-10-10T09:00:00Z"`. Посетители увидят его в своём часовом поясе. Пока времени нет, показывается `dateNote`.

**Нижняя сетка, раунд 2.** Точные пары известны только после раунда 1, поэтому в `LB-R2-1` и `LB-R2-2` стоят текстовые заглушки. Когда пары появятся, замените `a` и `b` на коды команд, например `a: "G2", b: "LOUD"`.

**Обновить дату обновления.** Измените поле `updated` в начале файла, оно показывается внизу страницы.

## Структура

```
index.html        разметка и подключение скриптов
data.js           все данные турнира
assets/core.js    логика: пересчёт сетки, таблиц групп, статусов матчей
assets/app.js     интерфейс: вкладки, часовой пояс, отрисовка
assets/style.css  оформление, светлая и тёмная темы
```

## Важно

- Статус «возможно идёт» сайт определяет по времени начала: он считает матч идущим в течение 3,5 часов после старта, пока в `data.js` нет счёта. Реальный ход матча сайт не знает.
- Неофициальный фанатский проект, не связан с Riot Games. Сверяйте результаты с официальными источниками.
