# VCT Champions 2026: сайт с сеткой, группами и расписанием

Статический сайт без сборки и серверной части. Работает на GitHub Pages как есть.

## Что внутри

- **Обзор**: ближайший матч с обратным отсчётом, матчи сегодняшнего дня, кто остался в плей-офф.
- **Плей-офф**: верхняя и нижняя сетка, клик по команде подсвечивает её путь.
- **Группы**: таблицы GSL с результатами и статусами (в плей-офф или вылет).
- **Расписание**: время в выбранном часовом поясе, фильтры «Все / Предстоящие / Сыгранные».
- **Команды**: все 16 участников, фильтры по статусу и региону, поиск, «моя команда» (звёздочка).
- **Гайд**: сопоставление CS и Valorant, термины формата, где смотреть.
- Выбор часового пояса, «моя команда» и тема (светлая, тёмная, авто) запоминаются в браузере.

## Структура

```
index.html        разметка и подключение скриптов
data.js           все данные турнира
assets/core.js    логика: пересчёт сетки, таблиц групп, статусов матчей
assets/app.js     интерфейс: вкладки, часовой пояс, отрисовка
assets/style.css  оформление, светлая и тёмная темы
```

## Важно

- Статус «возможно идёт» сайт определяет по времени начала: он считает матч идущим в течение 3,5 часов после старта, пока в `data.js` нет счёта. Реальный ход матча сайт не знает.
- Неофициальный фанатский проект, не связан с Riot Games. Сверяйте результаты с официальными источниками.
